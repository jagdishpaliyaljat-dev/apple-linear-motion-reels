### 1.1 Minimum Duration & Script Depth Mandate (45s–60s)
- **STRICT DURATION MANDATE**: Every autonomous single-topic video MUST be strictly between **45 and 60 seconds** long (minimum 45s, target 50s–55s).

### 1.2 Hinglish Retention Scripting Standard (Conversational Flow + English Visuals)
High-retention mobile short-form video succeeds through conversational intimacy and immediate relatability:
- **Conversational Hinglish Voiceover**:
  - The voiceover script must be written in natural, engaging conversational Hinglish—combining Hindi sentence structure, transitions, and conversational cadence with crisp English technical, scientific, or domain terminology.

- **Strict Visual Contrast Separation (English-Only Visual Typography)**:
  - While the spoken voiceover is in conversational Hinglish, **ALL on-screen kinetic captions and UI elements MUST remain in clean, high-contrast English**:
    - Upper-Third Captions: `["PASSIVE READING", "IS A TRAP"]`, `["ACTIVE RECALL", "SYSTEM"]`.

## 2. The 5 Core Studio-Grade Motion-Craft Rules (Kinetic Polish)

Amateur video animations feel stiff and PowerPoint-like because single cards sit statically on screen, transitions use linear timing, and text abruptly pops in and out. To achieve studio-grade After Effects and Linear.app polish, every composition MUST implement these 5 non-negotiable motion-craft rules:

```
┌────────────────────────────────────────────────────────────────────────┐
│               5 MANDATORY MOTION-CRAFT RULES (STUDIO POLISH)           │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 4-Stage Dynamic Camera Rig  │ Punch-In -> Focus Pan -> Recoil -> Out│
│ 2. Multi-Layered UI Layouts    │ Split-Screen, Bento-Grid, SVG Charts  │
│ 3. Dual-Font Kinetic Captions  │ Inter 800 + Instrument Serif Italic   │
│                                │ with directional blur-in & blur-out   │
│ 4. Velocity Motion Blur        │ blur(4px -> 0px) + {d:18, s:120, m:0.8}│
│ 5. Micro-Interactive Living UI │ Live counters, SVG cursor click ripple│
└────────────────────────────────────────────────────────────────────────┘
```

### 2.1 Rule 1: 4-Stage Dynamic Camera Rig (Cinematic Choreography)
Never use a flat, single-stage 1.0 -> 1.08 linear zoom across the entire scene. In studio motion graphics, the camera is an active director that guides the viewer's eyes through 4 distinct stages:
1. **Stage 1 (Punch-In Entrance: 0%–20% of scene duration)**:
   - Dynamic entrance snap: camera punches in rapidly from wide `scale: 0.94` up to `scale: 1.05` using critically-damped spring mechanics (`{ damping: 18, stiffness: 120, mass: 0.8 }`), centering the scene with commanding momentum.
2. **Stage 2 (Detail Focus Zoom & Pan: 20%–60% of scene duration)**:
   - Deep-dive into active content: as the narrator highlights a specific line of code, metric chip, or active step, camera zooms in tighter (`scale: 1.05 -> 1.18`) and pans purposefully (`translateX: -40px, translateY: +30px`) to frame the active element in sharp focus.
3. **Stage 3 (Action Micro-Recoil: 60%–72% of scene duration)**:
   - Physical impact response: when an inline cursor clicks, a checkmark triggers, or an alert pops, camera experiences a subtle micro-recoil dip (`scale: 1.18 -> 1.15`), giving the UI tactile weight.
4. **Stage 4 (Macro Pull-Back Overview: 72%–100% of scene duration)**:
   - Full composition reveal: camera smoothly pulls back (`scale: 1.15 -> 1.02`, `translateX: 0, translateY: 0`) with cubic deceleration, showing the entire multi-card system and final status bar before the scene cut.

### 2.2 Rule 2: Multi-Layered & Split-Screen UI Box-Model (Zero Single-Box Slides)
Under NO circumstances should any scene consist of a single isolated box in the center of the canvas. Every scene must deploy multi-layered depth across 4 signature composition patterns:
1. **Split-Screen Canvas (The Linear/Harness Signature)**:
   - Top Zone (58% of canvas height, Y: 320 to 1100): Interactive Browser or UI card panning horizontally across steps `01 -> 02 -> 03`.
   - Bottom Zone (38% of canvas height, Y: 1140 to 1760): Live streaming monospace terminal console with animated log lines, green checkmarks, and blinking cursor.
2. **Bento-Grid Module**:
   - Main focal card (60% area) paired with 2 floating diagnostic chips or utility pills (40% area) stacked vertically or horizontally.
3. **Interactive Bezier SVG Line-Chart**:
   - Glowing continuous Bezier curve (`<path d="M ... C ...">`) across milestone nodes with radiant drop-shadow glow and animated progress meters.
4. **Orbital Hub & Floating HUD Inspector Panels**:
   - Central glowing hub connected via animated dashed SVG lines (`strokeDasharray="6 6"`) to 3 satellite pills, accompanied by a detached floating HUD Inspector panel (`top: 480, right: 60`).
5. **Standardized Box-Model Hygiene**:
   - All cards use `borderRadius: 18` (Apple standard), `height: 'auto'`, and `padding: '36px 32px'`.
   - Inner pills and badges use `borderRadius: 12` (or `borderRadius: 9999`).
   - Cards enforce `overflow: 'hidden'` so large headlines (like `"UNSTOPPABLE"`) have minimum 32px vertical clearance and NEVER cross container borders.
   - Every card features an animated progress bar (`height: 4px–6px`) or telemetry status track in its lower area to eliminate hollow, dead space.

### 2.3 Rule 3: Dual-Font Kinetic Captions with Directional Blur-Out Exits
Captions must deliver high-fashion editorial contrast and fluid kinetic movement:
1. **Dual-Font Phrase Pairing**:
   - Combine modern industrial Sans-Serif (**Inter 800 Bold**) with elegant Editorial Serif (**Instrument Serif Italic 400**) in the *exact same phrase*:
     - `"True agents "` (Inter Bold 800) + `"THINK "` (Instrument Serif Italic 400) + `"and "` (Inter Bold 800) + `"EXECUTE."` (Inter Bold 800 in Electric Blue `#2563EB`).
2. **Directional Blur-In Entrance**:
   - Phrases enter with a fluid spring: rising `translateY(12px -> 0px)` while de-blurring from `blur(8px)` down to `blur(0px)`.
3. **Directional Blur-Out Exit (Zero Abrupt Pop-Outs)**:
   - When a phrase finishes speaking, it must NEVER abruptly disappear with a hard cut. During the final 8–10 frames before the next phrase, it must smoothly blur out directionally: rising `translateY(0px -> -12px)`, blurring `blur(0px -> 8px)`, and fading `opacity: 1 -> 0`.
4. **Upper-Third Safe Positioning**:
   - Position kinetic captions in the upper third (`top: 180px - 220px`) with high contrast so they never collide with the multi-layered UI hardware below.

### 2.4 Rule 4: Velocity Motion Blur & Critically Damped Springs
- **Critically Damped Physics Standard**: All card, window, and badge entrances MUST use Remotion `spring` configured with:
  ```ts
  config: { damping: 18, stiffness: 120, mass: 0.8 }
  ```
  This eliminates cheap bouncy oscillation while delivering crisp, rapid deceleration into position.
- **Velocity-Driven Motion Blur**: High entrance velocities produce natural camera lens motion blur. Calculate velocity from the spring delta and map it to CSS blur:
  ```ts
  const entranceProgress = spring({
    frame: localFrame,
    fps,
    config: { damping: 18, stiffness: 120, mass: 0.8 },
  });
  const motionBlur = interpolate(entranceProgress, [0, 0.75, 1], [4, 1.2, 0], {
    extrapolateRight: 'clamp',
  });
  ```
  Apply `filter: blur(${motionBlur}px)` alongside `translateY` or `scale` to give elements physical mass and optical realism.

### 2.5 Rule 5: Micro-Interactive Living UI Details
Static dummy interfaces look dead. Living software responds to actions:
1. **Live Animated Metric Counters**:
   - Numbers count up smoothly from `0` to the target value using Remotion `interpolate()` with cubic deceleration (`fontVariantNumeric: 'tabular-nums'`).
2. **Simulated Mouse Cursor Clicks (Crisp Inline SVG Arrow)**:
   - Pointer arrow is ALWAYS a clean inline `<svg>` pointer (white fill `#FFFFFF`, 1.75px `#09090B` stroke, drop shadow). NEVER draw cursors using filled square divs.
   - At the click frame, cursor compresses (`scale: 0.85`), button depresses (`scale: 0.96`), expanding concentric ripple ring radiates out (`scale: 1 -> 2.2`, `opacity: 0.8 -> 0`), and a crisp `click.mp3` triggers.
3. **Live Blinking Typing Cursors**:
   - Code blocks and terminal console lines display an active blinking cursor (`|` or vertical rectangle `#38BDF8`) pulsing with an alternating cycle (`Math.floor(frame / 15) % 2 === 0`).

### 4.1 `DynamicCameraRig`: 4-Stage Keyframed Choreography Container
```tsx
import React from 'react';
import { useCurrentFrame, interpolate, Easing } from 'remotion';

export interface DynamicCameraRigProps {
  children: React.ReactNode;
  durationInFrames: number;
  focusPanX?: number; // Target pan X during Stage 2 (e.g. -40)
  focusPanY?: number; // Target pan Y during Stage 2 (e.g. +30)
  focusScale?: number; // Zoom level during Stage 2 (e.g. 1.18)
}

export const DynamicCameraRig: React.FC<DynamicCameraRigProps> = ({
  children,
  durationInFrames,
  focusPanX = -40,
  focusPanY = 30,
  focusScale = 1.18,
}) => {
  const frame = useCurrentFrame();
  const progress = Math.min(1, Math.max(0, frame / durationInFrames));

  // 4-Stage Choreography Keyframes:
  // 0.00 -> 0.18: Stage 1 Punch-In (0.94 -> 1.05)
  // 0.18 -> 0.58: Stage 2 Detail Focus Zoom & Pan (1.05 -> focusScale, pan to focusPanX/Y)
  // 0.58 -> 0.72: Stage 3 Action Micro-Recoil (focusScale -> focusScale - 0.04)
  // 0.72 -> 1.00: Stage 4 Macro Pull-Back Overview (recoil -> 1.02, pan -> 0, 0)
  const scale = interpolate(
    progress,
    [0, 0.18, 0.58, 0.72, 1.0],
    [0.94, 1.05, focusScale, focusScale - 0.03, 1.02],
    {
      easing: Easing.bezier(0.25, 0.1, 0.25, 1.0),
      extrapolateLeft: 'clamp',
      extrapolateRight: 'clamp',
    }
  );

  const panX = interpolate(
    progress,
    [0, 0.18, 0.58, 0.72, 1.0],
    [0, 0, focusPanX, focusPanX * 0.8, 0],
    {
      easing: Easing.bezier(0.25, 0.1, 0.25, 1.0),
      extrapolateLeft: 'clamp',
      extrapolateRight: 'clamp',
    }
  );

  const panY = interpolate(
    progress,
    [0, 0.18, 0.58, 0.72, 1.0],
    [0, 0, focusPanY, focusPanY * 0.8, 0],
    {
      easing: Easing.bezier(0.25, 0.1, 0.25, 1.0),
      extrapolateLeft: 'clamp',
      extrapolateRight: 'clamp',
    }
  );

  return (
    <div
      style={{
        width: 1080,
        height: 1920,
        overflow: 'hidden',
        position: 'relative',
        transformOrigin: '50% 48%',
        transform: `scale(${scale}) translate(${panX}px, ${panY}px)`,
        willChange: 'transform',
      }}
    >
      {children}
    </div>
  );
};
```

### 4.2 `DualFontKineticCaption`: Inter 800 + Instrument Serif Italic with Directional Blur-Out
```tsx
import React from 'react';
import { useCurrentFrame, useVideoConfig, spring, interpolate } from 'remotion';

export interface CaptionSegment {
  text: string;
  style: 'sans-bold' | 'serif-italic' | 'accent-blue' | 'accent-emerald';
}

export interface KineticPhrase {
  segments: CaptionSegment[];
  startFrame: number;
  endFrame: number;
}

export const DualFontKineticCaption: React.FC<{
  phrases: KineticPhrase[];
  invertedTheme?: boolean;
}> = ({ phrases, invertedTheme = false }) => {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();

  // Find currently active phrase
  const activePhrase = phrases.find(p => frame >= p.startFrame && frame < p.endFrame);
  if (!activePhrase) return null;

  const phraseDuration = activePhrase.endFrame - activePhrase.startFrame;
  const localFrame = frame - activePhrase.startFrame;

  // 1. Directional Blur-In Entrance (first 10 frames)
  const entranceSpring = spring({
    frame: localFrame,
    fps,
    config: { damping: 18, stiffness: 120, mass: 0.8 },
  });
  const blurIn = interpolate(entranceSpring, [0, 1], [8, 0], { extrapolateRight: 'clamp' });
  const translateYIn = interpolate(entranceSpring, [0, 1], [12, 0], { extrapolateRight: 'clamp' });
  const opacityIn = interpolate(entranceSpring, [0, 0.4, 1], [0, 0.85, 1]);

  // 2. Directional Blur-Out Exit (last 10 frames before phrase ends)
  const exitFramesLeft = Math.max(0, activePhrase.endFrame - frame);
  const isExiting = exitFramesLeft < 10;
  const exitProgress = isExiting ? (10 - exitFramesLeft) / 10 : 0;
  const blurOut = interpolate(exitProgress, [0, 1], [0, 8], { extrapolateRight: 'clamp' });
  const translateYOut = interpolate(exitProgress, [0, 1], [0, -12], { extrapolateRight: 'clamp' });
  const opacityOut = interpolate(exitProgress, [0, 0.7, 1], [1, 0.3, 0]);

  const currentBlur = isExiting ? blurOut : blurIn;
  const currentTranslateY = isExiting ? translateYOut : translateYIn;
  const currentOpacity = isExiting ? opacityOut : opacityIn;

  return (
    <div
      style={{
        position: 'absolute',
        top: 200,
        left: 0,
        width: 1080,
        display: 'flex',
        justifyContent: 'center',
        alignItems: 'center',
        pointerEvents: 'none',
        zIndex: 100,
      }}
    >
      <div
        style={{
          display: 'flex',
          flexWrap: 'wrap',
          justifyContent: 'center',
          alignItems: 'baseline',
          gap: '12px 14px',
          maxWidth: 960,
          padding: '0 32px',
          transform: `translateY(${currentTranslateY}px)`,
          filter: `blur(${currentBlur}px)`,
          opacity: currentOpacity,
          willChange: 'transform, filter, opacity',
        }}
      >
        {activePhrase.segments.map((seg, idx) => {
          let fontStyle: React.CSSProperties = {
            fontFamily: 'Inter, sans-serif',
            fontSize: 48,
            fontWeight: 800,
            letterSpacing: '-0.02em',
            color: invertedTheme ? '#09090B' : '#FAFAFA',
          };

          if (seg.style === 'serif-italic') {
            fontStyle = {
              fontFamily: "'Instrument Serif', 'Playfair Display', Georgia, serif",
              fontSize: 54,
              fontStyle: 'italic',
              fontWeight: 400,
              letterSpacing: '0.01em',
              color: invertedTheme ? '#1E293B' : '#E4E4E7',
            };
          } else if (seg.style === 'accent-blue') {
            fontStyle = {
              fontFamily: 'Inter, sans-serif',
              fontSize: 48,
              fontWeight: 800,
              letterSpacing: '-0.02em',
              color: '#38BDF8',
              textShadow: '0 0 24px rgba(56, 189, 248, 0.5)',
            };
          } else if (seg.style === 'accent-emerald') {
            fontStyle = {
              fontFamily: 'Inter, sans-serif',
              fontSize: 48,
              fontWeight: 800,
              letterSpacing: '-0.02em',
              color: '#10B981',
              textShadow: '0 0 24px rgba(16, 185, 129, 0.5)',
            };
          }

          return (
            <span key={idx} style={fontStyle}>
              {seg.text}
            </span>
          );
        })}
      </div>
    </div>
  );
};
```

### 4.3 Scene 1 Archetype: `HookCodeWindowWithHUD` (Dual-Layer Window + Floating Status HUD)
```tsx
import React from 'react';
import { spring, useCurrentFrame, useVideoConfig } from 'remotion';

export const HookCodeWindowWithHUD: React.FC<{
  codeLines: string[];
  startFrame?: number;
}> = ({ codeLines, startFrame = 0 }) => {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();
  const localFrame = Math.max(0, frame - startFrame);

  const windowSpring = spring({ frame: localFrame, fps, config: { damping: 18, stiffness: 120, mass: 0.8 } });
```

## 5. Audio Mastering & Ambient Bed Standard (-28dB)

Dead digital silence between spoken phrases causes viewer detachment on social media feeds. Every mastered video MUST mix a continuous, low-volume (`-28dB`) procedural dark-tech ambient pulse/pad underneath the voiceover and UI SFX:

### 5.1 Procedural Ambient Bed Generation (Zero-Dependency Synthetic Pad)
If a pre-recorded dark ambient track is not in `public/sfx/`, generate a smooth, cinematic 55Hz sub-bass dark-tech pulse pad procedurally using FFmpeg:
```bash
ffmpeg -y -f lavfi \
  -i "sine=frequency=55:sample_rate=48000:duration=60,volume=-28dB" \
  public/sfx/ambient_bed.mp3
```

### 5.2 Multi-Track Audio Mastering Pipeline
Combine voiceover, continuous ambient bed (`-28dB`), UI SFX (whooshes, clicks, pops), and EBU R128 international broadcast loudness targeting:
```bash
ffmpeg -y \
  -i out/raw_video.mp4 \
  -i public/voiceover.mp3 \
  -i public/sfx/ambient_bed.mp3 \
  -i public/sfx/whoosh.mp3 \
  -i public/sfx/pop.mp3 \
  -i public/sfx/click.mp3 \
  -filter_complex "
    [1:a]adelay=0|0[vo];
    [2:a]volume=-28dB,adelay=0|0[amb];
    [3:a]adelay=0|0[w1];
    [3:a]adelay=3000|3000[w2];
    [3:a]adelay=6500|6500[w3];
    [3:a]adelay=9500|9500[w4];
    [4:a]adelay=1200|1200[p1];
    [4:a]adelay=4200|4200[p2];
    [5:a]adelay=5200|5200[c1];
    [vo][amb][w1][w2][w3][w4][p1][p2][c1]amix=inputs=9:weights=1.0 0.04 0.25 0.25 0.25 0.25 0.3 0.3 0.35[mixed];
    [mixed]loudnorm=I=-16:LRA=11:TP=-1.5[aout]
  " \
  -map 0:v -map "[aout]" \
  -c:v copy -c:a aac -b:a 192k \
  out/final_apple_linear_reel.mp4
```

## 6. Pre-Render & Post-Render Quality Gate Checklist

Before marking any Remotion motion-graphics code as production-ready:
- [ ] **Multi-Layered UI Compositions**: ZERO monolithic single-box slides; video features Split-Screen (Browser + Terminal), Bento-Grid alert modules, Bezier line charts, and floating HUDs.
- [ ] **4-Stage Dynamic Camera Rig**: Every scene is wrapped in `DynamicCameraRig` with 4-stage keyframed choreography (Stage 1 Punch-In -> Stage 2 Detail Focus & Pan -> Stage 3 Micro-Recoil -> Stage 4 Pull-Back Overview); ZERO flat linear drifts.
- [ ] **Dual-Font Kinetic Captions**: Kinetic captions render 2–4 word phrases combining Inter 800 Bold and Instrument Serif Italic 400 with directional blur-in (`blur(8px) -> 0px`) and directional blur-out (`blur(0px) -> 8px`); ZERO abrupt pop-outs.
- [ ] **Standardized Box-Model Hygiene**: Card `borderRadius: 18`, inner pills `borderRadius: 12`, `height: 'auto'`, and `padding: '36px 32px'` wrapping content snugly.
- [ ] **Zero Text-Border Collision**: Hero payoff `"UNSTOPPABLE"` sits strictly INSIDE the card with `overflow: 'hidden'`, never touching container borders.
- [ ] **Orbital Satellite Centering**: Satellite pills use centered flex alignment with `borderRadius: 16` so text sits centered INSIDE the rounded pill rather than floating above it.
- [ ] **Hinglish Retention Mode**: Spoken voiceover is written in natural, engaging conversational Hinglish, while ALL upper-third captions and UI cards remain in 100% clean, high-contrast English.
- [ ] **45s–60s Duration Mandate**: Spoken voiceover is 115–140 words, total video duration is strictly 45s–60s (target 50s–55s) unless user explicitly requested a short clip.
- [ ] **Velocity Motion Blur & Spring Physics**: Entrances use critically-damped springs (`{ damping: 18, stiffness: 120, mass: 0.8 }`) coupled with optical velocity blur (`blur(4px -> 0px)`).
- [ ] **Micro-Interactive UI Details**: Includes live animated metric counters counting up from `0` to target value, crisp inline `<svg>` cursor clicks (white fill `#FFFFFF`, 1.75px `#09090B` stroke, drop shadow, never a solid black block), and live typing cursors inside code/terminal windows.
- [ ] **Subtle Ambient Audio Bed (-28dB) & Natural Pacing**: Low-volume (`-28dB`) procedural dark-tech ambient pulse/pad continuously mixed underneath VO and SFX with TTS speaking rate at `+8%` for crisp, energetic delivery.
- [ ] **Automated Frame-Check Gate**: 4 still frames extracted (`05s`, `15s`, `30s`, `45s`) via FFmpeg and verified for zero text clipping or layout overflow.
- [ ] **Automated Spell-Check Passed**: Dedicated proofreading audit on all caption strings, card titles, subtitles, and code strings; zero typographical errors.
- [ ] **60-30-10 Spatial Rule & Max 2 Accents**: Compliant spatial distribution across both Dark and Inverted Light canvases with no more than 2 accent colors per scene.
- [ ] **Zero Unicode Emojis**: Always use styled CSS dots or inline SVG vector paths; zero raw emojis.
- [ ] Audio output passed through EBU R128 `loudnorm=I=-16:LRA=11:TP=-1.5` with whoosh, pop, and click SFX.
